1. **吞吐量**：4.06 → 6.45 → 8.92 个/min（边际增量：+2.39/2车，+2.47/3车）。各区间增益接近，尚未出现明显拐点，与排队论直觉一致。

3. **空载行驶率**：49.0% → 48.3% → 46.7%。车越多接单距离越短，空驶占比收窄。

## 四、结论与建议

- 在本地图与 λ=0.6/s 强度下，车队从 3 扩到 8 台吞吐保持近线性上行，未见明显拐点。
