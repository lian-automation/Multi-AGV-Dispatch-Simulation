## 三、结果分析（仿真验证值口径，文字由数据生成）

1. **吞吐量**：4.01 → 6.19 → 8.99 个/min（边际增量：+2.18/2车，+2.8/3车）。各区间增益接近，尚未出现明显拐点，与排队论直觉一致。
2. **响应时间**：平均 1306.824 → 753.752 → 451.801 s。本口径为突发注单饱和压测，响应时间包含排队等待：车越少队列越长，故随车队扩大显著下降；日常演示强度下任务即到即派，派单延迟为亚秒级。
3. **空载行驶率**：50.0% → 51.4% → 46.6%。车越多接单距离越短，空驶占比收窄。
4. **死锁与重规划**：物理死锁（按环去重）33 / 54 / 74 起、消除 33 / 54 / 74 起；仲裁触发 33 / 54 / 77 次（同一环冷却期后的重复仲裁不再计入"发生"）；12 个环曾让路无解而原地等待，待阻挡格局变化后自行恢复。占格冲突计数为 0——该值来自引擎每拍执行的"一格一车"不变式断言（两车同格/占格无主/幽灵占用预约记录，违规即 fail-fast），是【被测量的机制保证】，而非设计推断。
5. **低电回充**：全矩阵触发 8 次，各场景成功率 100%、100%、未触发（"未触发"表示该场景里程未使电量跌破阈值，属正常现象）。

## 四、结论与建议

- 在本地图与 λ=0.6/s 强度下，车队从 3 扩到 8 台吞吐保持近线性上行，未见明显拐点。
