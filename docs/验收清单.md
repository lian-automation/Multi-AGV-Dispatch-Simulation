## 4. 补充验证记录（2026-08-23 实机）

1. **干净环境复现**：新建 .venv → `pip install -r requirements.txt` 成功，
   导入版本 numpy 2.5.1 / flask 3.1.3 / pymodbus 3.6.9 与锁定一致；
2. **main.py 入口实跑**：`python main.py --headless --cars 5 --lam 0.3`
   持续运行无异常（引擎线程正常推进）；
3. **看板控制接口**：
   - `POST /api/pause` → 暂停期间 sim_time 冻结（26.0→26.0），恢复后继续增长；
   - `POST /api/agv/99/reset` → 404；`POST /api/agv/1/reset`（非故障车）→ ok:false；
   - `POST /api/call/2` → 返回 `via: Modbus HR2=1`，事件日志出现
     "任务#N(出库)…［站台3呼叫］"，全链路闭环。
