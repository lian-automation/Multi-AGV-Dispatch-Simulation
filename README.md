# 多 AGV 调度与交通管制仿真

> 电气自动化应届生求职作品集项目 · 纯软件调度层仿真
> Windows 10 + Python 3.12 | 仅用 numpy / flask / pymodbus（全开源免费）| 前端 ECharts(CDN) + 原生 Canvas

---

## ⚠️ 先读我：这是什么、不是什么

**这是"调度层"的离散事件仿真**：栅格地图上的 AGV 是抽象质点，研究的是
**任务怎么派、路径怎么规划、路权怎么管、死锁怎么解**。

它**不涉及也不模拟**：SLAM 导航定位、底盘运动控制、路径跟踪、真实电池/电机模型。
所有性能指标均为**仿真验证值**，不代表实车现场表现。

## 快速开始

```bat
:: 0) 环境：Windows 10 + Python 3.12（python --version 验证）
cd /d E:\Multi-AGV-Dispatch-Simulation
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

:: 1) 一键启动（Modbus从站 + 仿真引擎 + Web看板）
python main.py

:: 2) 浏览器打开看板（注意端口是 5010，避开本机其他 Flask 项目）
http://127.0.0.1:5010
```

可选动作：

| 想做什么 | 命令 / 操作 |
|---|---|
| 验证 Modbus 呼叫闭环 | 新终端 `python -m plc_link.modbus_client_test`（预期打印 **PASS**） |
| 用网页按钮模拟站台呼叫 | 看板顶部 ST1~ST4 按钮（走真实 HRk=1 寄存器链路） |
| 点击小车看详情 | Canvas 中点车：电量/状态/任务/剩余路径；故障车可点"人工复位" |
| 改车队规模 / 任务强度 | `python main.py --cars 8 --lam 0.6` |
| 不启动 Modbus 从站 | `python main.py --no-modbus` |
| 跑压力测试矩阵 | `python run_stress.py` → 自动生成 `docs/压测报告.md` |

## 性能指标（全部为【仿真验证值】）

> 口径：30×20 栅格地图（214 货位），200 个任务按泊松 λ=0.6/s 突发注单，
> Δt=0.2s 离散步进，固定随机种子 20240601，结果可复现。
> 详细表格见 [docs/压测报告.md](docs/压测报告.md)。

| 指标 | 3 台车 | 5 台车 | 8 台车 | 说明 |
|---|---|---|---|---|
| 任务完成率 | 200/200 | 200/200 | 200/200 | 全部场景满额消化 |
| **吞吐量（个/min）** | **4.06** | **6.45** | **8.92** | 随车队规模单调上升 |
| 平均任务响应时间（s） | 1300.5 | 704.6 | 439.6 | 含饱和排队时间，见下方口径说明 |
| 空载行驶率 | 49.0% | 48.3% | 46.7% | 空驶格数 / 总行驶格数 |
| 死锁发生 / 解除（次） | 27 / 26 | 47 / 44 | 70 / 64 | 其余在等待后自行消解 |
| 未解除原地等待（次） | 1 | 3 | 6 | 重规划无解时的如实上报 |
| 重规划次数 | 76 | 164 | 260 | 拥堵绕行 + 让路 |
| 低电回充成功率 | 100% | 80%* | -（未触发） | *场景结束时有车仍在充，未计入完成 |
| **车辆对撞次数** | **0** | **0** | **0** | 路权预约制的机制性保证 |

**响应时间口径说明**：压测刻意用突发注单制造排队，响应时间 = 到达→分配，
包含排队等待，反映吞吐-排队的守恒关系；日常演示模式（λ=0.3、5 车）下
任务即到即派，看板实测响应时间为亚秒级。

## 功能清单

- ✅ 泊松流任务生成：入库 / 出库 / 移库三类，强度 λ 可配；
- ✅ 最近空闲车优先分配（策略接口已预留拍卖法扩展位 `AuctionStrategy`）；
- ✅ A* 最短路（曼哈顿启发），支持动态避障重规划；
- ✅ 一格一车路权预约 + 纵深软预约，机制上杜绝对撞；
- ✅ 死锁检测（等待环 DFS 找圈）+ 让路重规划解除 + 无解原地等待计数上报；
- ✅ 低电(<20%)自动回最近充电站，充满归队；每任务 1% 故障待人工复位（看板按钮）；
- ✅ Modbus/TCP 从站模拟 4 站台呼叫盒（HR0~3 / HR10~13 / HR20 心跳）+ 自测脚本；
- ✅ Web 看板：Canvas 实时动画、点选详情、ECharts 吞吐/响应/电量三图、
  任务队列实时表、彩色事件日志（分配/让路/死锁/回充/故障）。
